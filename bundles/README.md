# bundles/

Unity 资源包。`.bundle`、`.unity3d`、`.cab` 属于这里。

## 放法

```
bundles/
└── <游戏代号>/
    ├── weapon-skin-v2.3.1.bundle
    └── notes.md
```

- 一层游戏代号目录，文件名里不再重复代号
- 同一份资源的不同版本并存，**不要覆盖**，版本号进文件名
- 每个游戏目录里可放一个 `notes.md`：适配的游戏版本、替换路径、已知问题

## 硬限制

单个文件 **100 MB 是硬上限**，超了推不上去。50 MB 起就该考虑走 Releases，
仓库里只留链接与 SHA256。见根目录 README 的「大文件怎么走」。

## 登记

放进来的同时，去 [INDEX.md](../INDEX.md) 补一行。缺 SHA256 的条目会被当成未完成。
